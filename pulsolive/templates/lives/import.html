¿De dónde saco el archivo?

  1. Entra a TikTok Shop Seller Center → Análisis → LIVE (o a LIVE Center si eres creador).
  2. Elige el rango de fechas y da clic en Exportar (CSV o Excel).
  3. Súbelo aquí. Reconocemos las columnas en español o inglés: fecha de inicio, duración, GMV, pedidos, espectadores, tiempo de visualización, etc.
  4. Si un live ya existe (mismo ID o misma hora de inicio) se actualiza, no se duplica.

¿Llevas tus lives en Excel propio? Usa la plantilla CSV. Puedes agregar columnas de Host, Promoción y Guion para no etiquetar después.
